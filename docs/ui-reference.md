阶段一实现列表的设计基础：近黑背景、灰色面板、黄绿色强调色、圆角9:16封面；宽桌面6列，中等屏幕3列，小屏2列；不强制照搬原品牌和人物素材。

阶段二/四详情调整为“左侧制作面板（标题、示例图、上传位、提交），右侧当前用户历史任务”。独立 /history 页面仍保留，方便刷新恢复和全量浏览。小屏制作面板在前，任务区在后，不要求横向滚动才能提交。

与原图有意区别：后端步骤和查询异常要比截图中的 Processing 更明确；不显示假进度。按钮有焦点和名称，失败有可理解原因。身份框显示演示 A/B 选择和说明，不扩展密码、账单、订阅、积分、账户删除、语言切换等题外功能。参考图中的垃圾桶和重试图标也不转化为需求。

原始截图仅在本机 docs/reference 保留并由 Git 忽略，不进入公开仓库或源码包；未放入 public 或后端 demo，不作为可公开分发业务素材。公开交付不依赖这些参考附件。

2026-11-01阶段四已用容器内Chromium生成并查看桌面/窄屏截图。公开交付保留本项目自有界面截图：[桌面制作](screenshots/create-desktop.png)、[窄屏制作](screenshots/create-mobile.png)。制作面板在左、任务卡在右；390px下制作在前、记录在后，顶部“我的记录”入口保持可见，无水平溢出。卡片明确区分排队/阶段/制作失败/查询中断，成功图可在命名对话框预览；Escape关闭并恢复焦点通过真实浏览器验证。这是布局与基本交互验收，不是逐像素还原或全面无障碍审计。
